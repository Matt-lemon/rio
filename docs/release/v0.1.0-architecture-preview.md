# v0.1.0 Architecture Preview — local release candidate

**Experimental / not production-ready. Not published.**

Rio is the system, not the LLM. This preview freezes existing Python code for
identity/model interfaces, Gate evidence policy, memory interfaces and durable
Execution Core. No new planner, worker framework or UI has been introduced.

The offline path calls the real read-only Core, then queries its durable result
from a fresh process. An existing crash test demonstrates no second mock dispatch
after process death. This does not imply distributed exactly-once execution or
physical-device success.

Personal configuration, state, credentials, media/model assets, unrelated patches
and large optional services are excluded. Deployment examples need independent
review. Known limitations include conservative legacy UNKNOWN blocking,
non-universal Gate routing, unencrypted state and external-provider ambiguity.
Actual voice/browser/device validation is not part of this preview.

See the [GPL/Apache comparison](v0.1-license-compatibility.md),
[provenance](v0.1-third-party-provenance.md), [privacy audit](v0.1-private-data-audit.md)
and [validation scope](validation.md). Root license selection, final rights/scope
review and owner publication approval are pending. Future integrations are not
represented as implemented or approved by this release.

The original private history is preserved in a private bundle. The public
candidate uses a separately normalized history with original commit timestamps;
privacy-driven hash/identity changes are documented in its audit record. Do not
publish the original repository or raw bundle instead of the reviewed candidate.
