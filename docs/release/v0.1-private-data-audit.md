# v0.1 private-data and history audit

2026-10-21. No credential values, actual internal hosts, personal absolute paths
or operational device identifiers are included in this report.

## Original private inventory

A private 0600 Git bundle preserves the original refs before filtering. The raw
bundle and original repository are not publication artifacts. An inventory
covered 20 worktrees, including tracked, untracked and ignored files; 888 unique
text snapshots were scanned. There were 269 working-area rule findings: 257 in
private state/logs, 4 credential/config findings, and 8 source/example/experiment
findings requiring review. Actual credential-format strings existed in ignored
configuration. They were not printed, copied into the preview, changed or
asserted never to have been exposed elsewhere.

Pinned Gitleaks 8.30.1 processed 297 original diff commits with no rule findings.
A separate inventory of 1349 reachable blob versions found personal paths in 225,
private-address patterns in 75 and UUID patterns in 25. Those original figures
are not reused as final-candidate results and include synthetic test fixtures.

## Normalized source-only candidate

Only the final public path allowlist is retained across history. Personal
configuration, data, logs, media/models, large optional components and unrelated
assets are excluded from every retained revision, not merely deleted at HEAD.
Documentation/example snapshots are normalized to the final reviewed public text;
they are not forensic copies of what an old private document said. Existing
runtime source receives reviewed example-literal substitutions only. No new
runtime function or execution framework is introduced.

All 278 mapped original commits preserve both author and committer timestamps.
Git author identities are pseudonymized, message bodies are removed, and known
personal deployment literals are normalized. The original attribution and
original-to-normalized hash mapping remain private. Subsequent release-check
commits are new dated commits. Original third-party license copyright text is
not replaced by Git pseudonyms.

A standalone fresh clone removes raw refs, private tags, original remotes and
unreachable original objects from the deliverable. Never use push --mirror on
the original repository in place of this candidate.

## Final checks and limits

The normalized candidate passes reachable-blob/metadata path checks. Its UUID
values are the two explicit synthetic 12345678 fixture identifiers; remaining
private-network literals are browser scope-denial test inputs, not deployment
hosts. Reviewed deployment hosts use documentation-only addresses. Gitleaks is
run on history, commit metadata and the working tree with redaction and inline
allow comments ignored. Check counts and exact source revision are in the
[validation record](validation.md).

Scanner success is evidence of specific detection checks, not a proof of all
possible secret/private-data absence. Binary redistribution is outside scope;
no model, wheel, media, database or executable bundle is included. Rights and
final owner review remain required. Original operating credentials, data,
services and other worktrees were not rewritten or restarted.
