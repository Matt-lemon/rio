# Third-party provenance — audit, not a root license grant

확인일: 2026-10-21. [파일별 판정](audit/candidate-file-decisions.csv)은 기존 CI 통합 snapshot 434개 파일과 신규 공개 문서를 구분한다. 원격 main의 63개 파일과 별도 구현의 범위를 혼동하지 않는다. 원본 Git의 최초 추가 commit/date/blob 전체 매핑은 private 감사 기록에 보존했다. 공개 CSV는 범위와 분류를 담는다. Git 작성자 기록은 출처 추적 근거이며 모든 저작권의 독점 소유를 증명하지는 않는다.

## Rio implementation and architectural reference

`core/execution/*.py`는 저장소의 `195e242`에서 Python 구현으로 들어왔다. 당시 문서는 Chat On Steroids의 공통 도구 등록, 실행 직전 권한 재검사, 영속 목표/결과·재개 경계를 참고했다고 기록한다. 참고 기준은 [6d2b98a61b2125a4bbfff744cc47dd81ea0bedc9](https://github.com/totec448-spec/chat-on-steroids/tree/6d2b98a61b2125a4bbfff744cc47dd81ea0bedc9/src/main)다.

정확한 commit의 LICENSE를 GitHub API로 확보해 MIT임을 확인했다. [해시 증거](audit/upstream-license-evidence.json)를 남겼다. Electron/ChatGPT 브라우저 자동화, 계정 연결 및 Windows 플러그인을 Rio 실행 코어로 이식했다는 주장은 하지 않는다. 실제 코드 이동이 추가 확인되면 해당 파일에 MIT 고지를 적용해야 하며, 문서의 design reference 표기로 이를 대체할 수 없다.

현재 검토 snapshot의 소스 문자열·경로·Git 이력에서 OpenAI Codex upstream의 실제 이식 파일을 식별하지 못했다. Codex 사용 기록이나 개인 작업 경로는 upstream 소스 복사 증거로 취급하지 않았다. 따라서 Codex 프로젝트의 라이선스를 Rio 전체에 가져오지 않는다. 이 검사는 코드 이동의 부재에 대한 완전한 증명이 아니며, 나중에 일치 소스가 확인되면 파일 단위 재검토가 필요하다.

## Actual MIT derivative, outside minimal preview

`services/rio-dubbing/native/tts-server.cpp`와 `resident-batch.patch`는 별도 음성 native 확장이다. [OmniVoice ed603581b2a9bf18fc055ca5de5d4a48960db01a](https://github.com/ServeurpersoCom/omnivoice.cpp/tree/ed603581b2a9bf18fc055ca5de5d4a48960db01a)의 `tools/tts-server.cpp` 및 baseline header 경로와 비교했다. Rio 서버 파일은 upstream과 동일 파일이 아니라 변경된 파생본이다.

보관된 `LICENSE.omnivoice`는 해당 upstream LICENSE와 byte-for-byte 일치했다. 두 root-license 안 모두 이 MIT 고지 보존이 필요하다. 빌드된 서버·ggml/ROCm DLL·모델·개인 음성 참조는 이 검증으로 배포 승인되지 않는다. v0.1 최소 범위에서는 이 native 구성 전체를 제외하는 것으로 판정했다.

## Dependencies and separately executed components

- `primp==2.0.1`: 설치 wheel의 LICENSE 파일 부재를 발견했다. 정확한 [v2.0.1 upstream](https://github.com/deedy5/primp/tree/v2.0.1)의 MIT LICENSE를 별도 확보했다. Rust 전이 라이브러리 전체가 MIT라는 뜻은 아니다.
- `certifi==2026.10.19`: 설치된 MPL-2.0 LICENSE와 파일 해시를 보존했다. Rio 라이선스로 덮어쓰지 않는다.
- `@playwright/mcp==0.0.83`: 정확한 npm metadata는 Apache-2.0이다. npm 전이 의존성·브라우저 배포 파일은 별도 미검증이다.
- FFmpeg/OpenCV wheel 내부 파일, 시스템 PortAudio, GPU/음성 엔진, Android SDK/샘플, Qdrant/PostgreSQL 서버와 모델 weights는 Rio 자체 소스 및 이번 Python metadata 검사와 구분한다. 실행 파일이나 state/data를 public tree에 복사하지 않는다.

## Quarantine decisions

`tools/your-mom-patch/**`는 Rio 핵심과 무관한 게임·asset 패치다. 제3자/게임 asset 권리가 공개 범위에서 확정되지 않아 제외한다. `services/rio-localization/rio_localization/seed-zh-ko.json`은 데이터 출처가 문서화되지 않아 별도 보류한다. 기존 screenshot·음성/캐릭터 asset·개인 실험/운영 기록도 제외한다. 이는 원본 파일 삭제나 권리 침해 판정이 아니라 공개 후보의 보수적인 범위 제한이다.

Rio 직접 작성 부분은 감사 후 사용자가 선택한 GPL-3.0-only를 적용한다. 외부 코드의 원래 라이선스·고지는 최종 선택으로 없어지지 않는다.
